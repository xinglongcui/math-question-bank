# 需求基线 · 2026-10-07

来源：用户指定的「少年班学习建议」对话，最新需求总结与用户确认的开发路线。

产品目标：iPad-first 的初一数学自适应题库。学校真实题目 → 结构分析 → 人工审核 → 同类型新变式 → 纸笔解答与拍照 → 批改 → 掌握状态 → 后续练习。

长期目标部署：GitHub + Vercel + Supabase。iPad Safari/PWA 独立使用，Windows 用于开发、管理和打印，无需常开。

当前选择（2026-10-07）：取消家庭邮箱登录，先用 Windows 本机题库。云端同步与 iPad 独立使用暂停；ChatGPT 订阅授权仍用于 AI 调用，原图和已有记录保留。

新增要求：支持多道题拍在同一张图片上，自动按主题拆分；每题共用原图、独立保存和审核。

## 必须保留

- 全部 AI 任务统一使用一个所选 ChatGPT 模型。使用 ChatGPT 订阅额度，不加入 OpenAI API key 计费回退。
- 两套标签：知识点、数学方法。学校原题与 AI 变式题分开。
- 题目分析：标准题干、表达式、答案、步骤、第一突破口、知识点、数学方法、难度、易错点、来源、日期。
- DNA：核心考点、方法、结构、条件、难度、运算复杂度、解题路径。
- 变式 V1 参数、V2 条件、V3 表达形式、V4 结构迁移。
- 生成和独立验题分为两个调用；验证答案、完整性、歧义、知识范围、考点一致性，审核后进入练习池。
- 掌握状态：S0 不会、S1 讲解后理解、S2 独立完成同类题、S3 独立解决新变式。S3 才视为掌握。
- 学校进度（未学/正在学/已学）与学生掌握状态分开；只训练已学内容。
- 今晚一题：10–15 分钟；依据教学内容、错误、知识点和方法薄弱项、复习间隔、掌握度选择新变式。
- 周末练习：30–45 分钟；30% 新知识、30% 薄弱项、20% 复习、20% 综合迁移。
